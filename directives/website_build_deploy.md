# Website Build & Deploy Workflow

## Overview

Build and deploy the Golf Kenya premium website with automatic product updates from Google Sheets.

## Current app-based storefront (October 2026)

- Owner preference (6 October 2026): build, edit and verify locally first. Do not upload draft previews or production deployments to Netlify, or push to a branch that triggers a Netlify build, until the owner is happy with the local result and explicitly approves that upload. Netlify deployments consume credits. Use `npm run admin:local` for the online-admin interface at `http://127.0.0.1:8787/admin/`; its clients, sales and catalogue edits stay in `.tmp/admin-local-data.json`, use the real validation handlers, and never call Google Sheets or Netlify. Treat local preview records as development data. Keep the legacy Flask backend's automatic publishing OFF.

- Standalone Karibu crowdfunding previews use a separate retained-template checkout in `.tmp/` and a fresh private Sites project; do not deploy them to the existing public storefront. Keep pre-launch rewards and community programmes labelled as proposed plans, and preserve unknown funding goals, dates and payment links.
- The original Golf Lessons design is retained in `.tmp/karibu-golf-lessons/`, using authentic campaign photography. Its Sites identity stays in that checkout's `.openai/hosting.json`; never copy the campaign or storefront project identity. The approved storefront version lives at `/Coaching`, is linked as **Golf Coaching** in the shared navigation and is exported through `execution/export-new-site-static.mjs`. Use `execution/verify_golf_lessons.mjs <local-coaching-url>` for pricing, WhatsApp messages, goal tabs, FAQs, keyboard navigation, mobile, reduced-motion, no-JavaScript and 200% text checks; evidence stays in `.tmp/golf-lessons-qa/`. Confirm venue and additional fees through booking, and do not publish an assessment-credit promotion without the owner's agreement. Place the skip link before navigation and hide it with clipping, rather than a fixed negative top offset that can expose it at 200% text. Scale display prices to their container in enlarged-text layouts. Publishing the standalone private Site does not authorize a Netlify storefront deployment.
- Windows Sites helpers: if the npm shim resolves a nonexistent checkout-local `node_modules/npm/bin`, invoke the installed npm CLI through Node with its absolute path instead. For Sites packaging, prepend the installed Git `bin` directory to the process PATH and set `TAR_OPTIONS=--force-local`; the default WindowsApps bash routes through WSL and cannot use native Windows paths, while GNU tar otherwise treats a drive-letter archive path as remote. Pass build commands as argument arrays through the workflow, keep source credentials only in memory/stdin, and renew the same project's credential when expired.

- Wait for two browser animation frames after an instant scroll before reading custom scroll state; skip frame waits in JavaScript-disabled contexts, where callbacks do not run.
